# Migration from extenM

The original `extenM.sh` bundled installation, Python 2 monitoring code, generated web files and systemd configuration in one shell script.

PBX Agent separates those responsibilities:

| extenM | PBX Agent |
|---|---|
| `monitor.py` generated by shell | `agent/` Python 3 package |
| Credentials injected into Python | `/etc/pbx-agent/pbx-agent.conf` |
| `/var/www/html/monitor` | Built-in HTTP dashboard |
| `state.json` under web root | `/var/lib/pbx-agent/state.json` |
| `asterisk-monitor.service` | `pbx-agent.service` |
| Python 2 | Python 3 |
| Polling JSON every second | API + event-driven AMI state |

The original dashboard monitored extension state using AMI endpoint/contact/extension events. PBX Agent preserves that core behavior while making the project installable and maintainable as a public repository.
